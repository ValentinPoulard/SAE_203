1. Description de l'architecture du projet

1.1 Organisation du serveur

Le projet est hébergé sur le serveur web Apache mis à disposition par l'IUT Saint-Malo. Il est composé de deux espaces distincts, accessibles depuis le même nom de domaine/adresse IP :

/                          ← Racine du serveur
├── infos.html             ← Page d'informations générale (sans CSS)
├── wiki.html              ← Cette page wiki (sans CSS)
│
├── vitrine/               ← Installation WordPress (site vitrine public)
│   ├── wp-admin/          ← Tableau de bord WordPress
│   ├── wp-content/
│   │   ├── themes/        ← Thème personnalisé avec charte graphique
│   │   └── plugins/
│   │       ├── partenaires/      ← Plugin maison : affichage des partenaires
│   │       └── temoignages/      ← Plugin maison : témoignages clients
│   └── ...                ← Fichiers cœur WordPress
│
└── intranet/              ← Application PHP développée from scratch
    ├── index.php          ← Page de connexion
    ├── dashboard.php      ← Tableau de bord après connexion
    ├── utilisateurs/      ← Gestion des comptes utilisateurs
    ├── fichiers/          ← Gestionnaire de fichiers partagés (txt, csv)
    ├── annuaire/          ← Annuaire des employés
    ├── partenaires/       ← Gestion des partenaires (sync avec vitrine)
    ├── clients/           ← Annuaire et fiches clients
    ├── data/              ← Fichiers JSON de stockage des données
    │   ├── utilisateurs.json
    │   ├── partenaires.json
    │   ├── employes.json
    │   ├── clients.json
    │   └── temoignages.json
    ├── uploads/           ← Fichiers partagés (txt, csv) par groupe
    ├── assets/            ← CSS surcharge Bootstrap, images, logos
    └── includes/          ← Fonctions PHP communes (auth, sessions, helpers)

1.2 Site vitrine (WordPress)

Le site vitrine est construit sur WordPress. Il utilise un thème personnalisé qui applique la charte graphique de l'entreprise. Deux plugins PHP sont développés par l'équipe :

  • Plugin Partenaires : lit les données JSON gérées dans l'intranet et affiche les logos et descriptions des partenaires sur une page WordPress.
  • Plugin Témoignages : lit un fichier JSON de témoignages et les affiche sous forme de cards Bootstrap via un shortcode [temoignages_clients].

La configuration Apache dédie un Virtual Host (ou un sous-répertoire) à WordPress. PHP 7.4+ est requis. Aucune base de données MySQL n'est utilisée pour l'intranet ; WordPress utilise sa propre base SQLite ou MySQL selon la configuration serveur.

1.3 Intranet (PHP from scratch)

L'intranet est une application web développée intégralement en PHP, HTML, CSS et Bootstrap 5, sans WordPress ni base de données MySQL. Toutes les données sont persistées dans des fichiers JSON. Le CSS personnalisé ne sert qu'à surcharger les couleurs de Bootstrap.

L'application repose sur un système de sessions PHP pour gérer l'authentification et les droits d'accès. Chaque page vérifie la session active avant d'afficher son contenu.

Groupes utilisateurs définis :

  • admin – accès complet à toutes les fonctionnalités
  • direction – accès en lecture/écriture sur les annuaires et partenaires
  • managers – accès aux fichiers partagés et annuaires
  • salaries – accès limité (lecture annuaire, dépôt/lecture fichiers selon droits)

1.4 Stockage des données

Toutes les données métier sont stockées dans des fichiers JSON situés dans intranet/data/. Les fichiers partagés par les utilisateurs sont stockés dans intranet/uploads/ et organisés par groupe. L'accès en lecture/écriture/suppression sur ces fichiers est contrôlé par une matrice de droits définie par groupe.

Les formats acceptés pour les fichiers partagés sont uniquement .txt et .csv.

1.5 Versionnement Git

Le projet est versionné sur GitHub. Chaque membre commit avec son adresse mail universitaire. Les membres suivants ont accès au dépôt en tant que collaborateurs : frmenguy, cD4v1D, aloisguitton.

2. Description et utilisation des fonctionnalités

2.1 Site vitrine

Le site vitrine est public et accessible sans connexion. Il présente l'entreprise à travers les pages suivantes :

Page Description URL exemple
Accueil Présentation générale de l'entreprise et de ses valeurs. /vitrine/
Qui sommes-nous ? Présentation des dirigeants et des membres principaux de l'équipe. /vitrine/qui-sommes-nous/
Histoire Chronologie de l'évolution de l'entreprise (changements de présidence, acquisitions, implantations géographiques…). /vitrine/histoire/
Activités Présentation des différents domaines d'activité de l'entreprise. /vitrine/activites/
Partenaires Logos et descriptions des partenaires, affichés via le plugin WordPress maison. Données gérées depuis l'intranet. /vitrine/partenaires/

2.2 Plugin WordPress – Partenaires

Rôle : Afficher dynamiquement les logos (en miniature) et les descriptions des partenaires de l'entreprise sur la page Partenaires de la vitrine.

Fonctionnement : Le plugin lit le fichier intranet/data/partenaires.json (partagé entre l'intranet et la vitrine) et génère l'affichage automatiquement.

Utilisation : Insérer le shortcode [partenaires_entreprise] dans la page WordPress souhaitée. Les données sont mises à jour depuis l'interface de gestion de l'intranet.

2.3 Plugin WordPress – Témoignages clients

Rôle : Collecter et afficher les témoignages de clients satisfaits sous forme de cards Bootstrap sur le site vitrine.

Données gérées par témoignage :

  • Nom du client
  • Entreprise du client
  • Citation (texte libre)
  • Note de 1 à 5 étoiles
  • Statut : actif / inactif

Interface d'administration (WP-Admin) : Un menu dédié « Gestion des témoignages » permet à l'administrateur de :

  • Ajouter un nouveau témoignage via un formulaire
  • Activer ou désactiver un témoignage (sans suppression)
  • Modifier un témoignage existant
  • Supprimer définitivement un témoignage

Affichage front-office : Insérer le shortcode [temoignages_clients] dans n'importe quelle page ou article WordPress. Seuls les témoignages avec le statut « actif » sont affichés. La note est rendue sous forme d'étoiles (★ pleine / ★ vide).

Stockage : Les données sont stockées dans un fichier JSON dans le répertoire du plugin.

2.4 Intranet – Portail de connexion

URL : /intranet/ ou /intranet/index.php

Accès : Réservé aux salariés de l'entreprise. La page affiche un formulaire de connexion (identifiant + mot de passe). En cas d'échec, un message d'erreur est affiché. En cas de succès, l'utilisateur est redirigé vers le tableau de bord selon son groupe.

La déconnexion est accessible depuis toutes les pages de l'intranet via un lien dans la barre de navigation.

2.5 Intranet – Gestion des utilisateurs

Accès : Réservé au groupe admin.

URL : /intranet/utilisateurs/

Cette section permet de :

  • Lister tous les comptes utilisateurs avec leur groupe d'appartenance
  • Ajouter un utilisateur (identifiant, mot de passe, profil, groupe(s))
  • Modifier les informations et le profil d'un utilisateur existant
  • Supprimer un compte utilisateur
  • Gérer les groupes : un utilisateur peut appartenir à plusieurs groupes simultanément

Les groupes disponibles sont : admin, direction, managers, salaries (et éventuellement des groupes personnalisés).

Stockage : intranet/data/utilisateurs.json

2.6 Intranet – Gestionnaire de fichiers partagés

URL : /intranet/fichiers/

Permet le partage de fichiers .txt et .csv entre collaborateurs selon les droits de chaque groupe. Les opérations disponibles dépendent du groupe de l'utilisateur connecté :

Action admin direction managers salaries
Voir la liste des fichiers Oui Oui Oui Oui (selon droits)
Visualiser un fichier Oui Oui Oui Oui (selon droits)
Ajouter un fichier Oui Oui Oui Non
Supprimer un fichier Oui Oui Non Non

Note : la matrice de droits définitive est fixée par l'équipe dans la documentation de conception du projet.

2.7 Intranet – Annuaire des employés

URL : /intranet/annuaire/

L'annuaire recense au minimum 12 personnes. Chaque fiche employé contient :

  • Nom et prénom
  • Fonction
  • Photo
  • Biographie

Consultation : Tous les utilisateurs connectés peuvent consulter l'annuaire complet.

Administration : Les utilisateurs autorisés (admin, direction) peuvent ajouter, modifier ou supprimer une fiche employé.

Stockage : intranet/data/employes.json + photos dans intranet/assets/photos/

2.8 Intranet – Annuaire des partenaires

URL : /intranet/partenaires/

L'annuaire recense au minimum 5 partenaires. Chaque fiche partenaire contient :

  • Nom de l'entreprise partenaire
  • Logo
  • Description affichée sur la vitrine

Administration : Ajout, modification et suppression d'un partenaire depuis l'intranet.

Lien avec la vitrine : Les informations gérées ici alimentent automatiquement la page Partenaires du site vitrine via le plugin WordPress dédié.

Stockage : intranet/data/partenaires.json + logos dans intranet/assets/logos/

2.9 Intranet – Annuaire des clients

URL : /intranet/clients/

L'annuaire recense au minimum 30 clients. Chaque fiche client contient :

  • Nom et prénom
  • Numéro de téléphone
  • Adresse e-mail
  • Adresse postale
  • Autres informations utiles

Fonctionnalités :

  • Afficher la liste complète des clients
  • Ajouter un nouveau client
  • Modifier les informations d'un client existant
  • Supprimer un client
  • Télécharger la fiche d'un client (export en fichier .txt ou .csv)

Stockage : intranet/data/clients.json
